# Privacy Policy

**Hermes Agent (personal OAuth client)** — Last updated: October 18, 2026

This application is a private, single-user tool operated by CJ Tully for personal productivity use. It connects a locally running AI assistant (Hermes Agent) to the operator's own Google account.

**Data accessed.** The app accesses Google Workspace data (Gmail, Calendar, Drive, Docs, Sheets, Contacts) belonging solely to the operator's own account, and only when the operator explicitly authorizes it.

**Data storage.** OAuth tokens and any retrieved data are stored locally on the operator's own machine. No data is transmitted to, stored on, or shared with any third-party server operated by the developer.

**Data sharing.** No user data is sold, shared, or disclosed to any third party. Data may pass through third-party APIs (e.g., an LLM provider) only as part of fulfilling a request the operator explicitly initiated.

**Data retention & deletion.** Data persists only on the operator's local device and can be deleted at any time by removing the local credential and cache files. Access can be revoked at https://myaccount.google.com/permissions.
